# Hiremate — AI Interview Readiness PM Simulator

An intelligent, interactive PM practice simulator designed for real-time interview preparation, behavioral evaluation, neural reasoning analytics, and personalized feedback.

## Features

- **Live AI Interview Simulation**: Real-time conversational interview practice with adaptive prompts.
- **Neural Reasoning Analytics**: Interactive visual graph displaying candidate reasoning flow and depth.
- **Audio Waveform & Speech-to-Text**: Live audio capture with interactive frequency waveform visualization.
- **Performance Evaluation**: Comprehensive feedback metrics, benchmark scoring, and improvement areas.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```
